# 北航 2026 秋季 中国式现代化题库

这是北京航空航天大学 2026 年秋季《中国式现代化的理论与实践》雨课堂习题的整理与检索页面。

> 题库用于课程复习和自测，不是学校发布的正式试卷，也不保证与期末考试原题完全一致。期末考试据课程安排从题库中抽取 50 道题，具体以任课教师的最终通知为准。

## 在线使用

打开 [题库搜索页面](https://pridezzh.github.io/chinese-modernization/) 即可直接检索。

页面为单文件离线网页，不依赖后端和第三方库。下载 `index.html` 后双击也可以使用。

## 页面功能

- 输入关键词，实时检索题干、选项、答案和简析，并高亮关键词。
- 按第一讲至第九讲、结语筛选。
- 按单选题、多选题、判断题筛选。
- 独立控制答案和解析的显示，适合先做题再核对。
- 随机抽取 50 题，作为期末考试规模的练习模式。
- 清除筛选后恢复全部题库。

## 文件说明

- [`index.html`](./index.html)：单文件题库搜索页面，打开即可使用。
- [`题库_完整版.md`](./题库_完整版.md)：第一讲至结语的完整 Markdown 汇总。
- [`题库_详版.md`](./题库_详版.md)：适合在编辑器中阅读的题干、选项、答案和简析版。
- [`题库_速查.md`](./题库_速查.md)：只保留题干关键词和答案，适合快速复习。
- `data/`：按讲次拆分的原始 Markdown 资料，便于单独阅读和后续修订。

## 本地使用

1. 下载或克隆本项目。
2. 直接打开 `index.html`。
3. 在搜索框输入关键词，例如“共同富裕”“碳达峰”“人才强国”。
4. 需要模拟考试时，点击“随机抽50题”；点击“返回全部题目”即可退出练习模式。

## 内容说明

题目来自用户整理的雨课堂作业截图和课程资料，答案与简析依据现有讲义、题目语境和课程复习内容整理。若教师在课堂或雨课堂中更新了答案，应以最新教学要求为准。欢迎通过 Issue 提交错题、重复题、题干缺字或答案争议。
