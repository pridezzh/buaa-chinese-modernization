## 使用入口

- [在线检索题库](https://pridezzh.github.io/buaa-chinese-modernization/)
- [下载 PDF 版题库](./中国式现代化题库.pdf)

在线页面支持关键词搜索、按讲次和题型筛选、隐藏答案与解析，以及随机抽取 50 题练习。PDF 版适合下载、打印或离线阅读。

## 仓库内容

本仓库只保留最常用的三项内容：

- `index.html`：单文件题库检索页面。
- `中国式现代化题库.pdf`：题干、选项、答案和简析的合并版。
- `README.md`：项目说明。

## 说明

本项目用于个人学习、课程复习和知识整理，不是学校发布的正式试卷或官方题库。答案与简析依据现有讲义、题目语境和课程复习内容整理；若教师在课堂或雨课堂更新答案，应以最新教学要求为准。
